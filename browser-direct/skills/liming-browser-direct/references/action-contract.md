# Browser Direct v0.4.0 MCP contract

`browser_task_open({scope,startUrl})` creates one new CDP Tab for unique scope: `project`, `clientRef`, `legalEntityRef`, `entity`, `entityType`, `fy`, `period`, `formType`, `matter`, `xeroOrgRef`, `xeroOrgLabel`, `returnRef`. `browser_task_bind({taskId,anchors:{client,year,form,organization,returnRef}})` verifies the exact return once, records ownership and issues `sessionId`. `browser_task_prepare` accepts only `navigate`, safe Xero anchor-link `click`, `scroll` or `wait` before initial bind; no form typing.

`browser_task_list` returns only hashed scope/state, task ID and owned target ID (no client names). `browser_task_pause`, `browser_task_resume`, `browser_task_recover` enforce explicit pause and event-driven revalidation before continuing. Normal `browser_fill_fields({sessionId,idempotencyKey,fields:[...]})` and `browser_act({sessionId,idempotencyKey,action,expectedPoststate?})` do NOT need a fresh full client identity/revision each time for managed task sessions; they check lightweight target/document integrity and individual values, never blindly retry a possible write. Legacy sessions require `expectedRevision` and are disabled in production.

`browser_verify_saved({sessionId,expectedRevision,idempotencyKey,saveActionKey,fields})` requires a verified same-session Save and confirms persisted values after reload. `browser_task_finish({taskId,expectedFields,closeTab:true})` does the final exact client/FY/form/org/return identity check and field audit then, if truly verified, closes ONLY the plugin-created Tab. `browser_task_close` permits a verified owned Tab or a never-prepared unbound owned Tab; never an arbitrary client tab. `browser_release` is unavailable for managed task ownership.

The runtime remains bound to HTTPS Xero origins, localhost CDP, independently attested Chrome owner, separate private tunnel and strict no-Lodge/Submit/Send/Sign/Pay/Delete authority. A transport timeout or uncertain commit requires reconciliation, not replay. An external operator that ignores this plugin's private Tab locks remains a separate Windows Live deployment risk.
