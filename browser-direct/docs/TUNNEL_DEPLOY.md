# v0.5.0 private reverse Tunnel — security-first staged deployment

Route: authenticated ChatGPT MCP -> HTTPS Gateway -> authenticated Windows outbound Agent -> localhost MCP 59422 -> Chrome CDP 9222. No public Chrome/CDP port. All three roles use distinct 32+ char secrets, provisioned independently through host secrets and Windows user-protected storage. Do not commit secrets, cookies or Chrome profiles to GitHub or Plugin source.

**TLS requirement:** production Gateway now requires directly terminated TLS at Node itself, with `LIMING_GATEWAY_TLS_CERT_FILE` and `LIMING_GATEWAY_TLS_KEY_FILE` mounted securely. It validates the real TLS socket (`req.socket.encrypted`). `X-Forwarded-Proto` is ignored because clients can forge it. A provider that only supplies an HTTPS reverse proxy with plaintext HTTP to this gateway must instead supply authenticated end-to-end TLS to the backend or use a separately reviewed trusted-proxy transport; never set a header to bypass this.

**Durable job receipts:** set `LIMING_GATEWAY_JOURNAL_PATH` to a persistently mounted writable disk. Queue acceptance, dispatch, reply and timeout are fsync-journalled before acknowledgement. `GET /result/<requestId>` requires frontend authentication and returns the state and digests, never raw tax values. On restart, any pending job remains UNKNOWN / no automatic replay. An actual stable Job result is still verified through the Windows action WAL + Chrome/Xero readback. Run a single Gateway instance with persistent storage unless a shared transactional broker is separately implemented and tested.

Deploy with `docker build -f tunnel/Dockerfile -t liming-browser-gateway:0.5.0 .` and securely mounted certificate/private key, persistent journal and three secrets. Start the authenticated Windows Agent after current Chrome owner/profile and Broker have been independently verified. Configure the host-supported private MCP connector to the real HTTPS URL; `mcp.json` remains deliberately unbound until the host actually exposes tools. If the host cannot store Bearer secrets securely, use host-supported OAuth/private authentication or stop `MCP_BINDING_UNAVAILABLE`.

The Gateway is not the tax expert, never interprets amounts or chooses target Tabs. Transport timeouts are `UNKNOWN_OUTCOME_NO_AUTOREPLAY`; use authenticated result inquiry and exact source readback instead of sending the command again.
